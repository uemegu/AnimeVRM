# タスク01：型、入力検証、品質計測

読む：`contract.md`、`src/ai/motion/ardy/createArdyAnimationClip.ts`、`src/motion/rig.ts`、`test/motion-editor-ardy.spec.ts`。

## 実装

1. 共通仕様の `types.ts`, `validate.ts`, `rig.ts`, `measure.ts` を追加する。まだ生成処理へ接続しない。
2. `collectPoseMetrics()` は対象ボーンの位置・回転を読んで、接触誤差・手の向き・腕の交差リスクを返す。
3. `collectClipMetrics()` は時系列から角速度・角加速度を求める。接触距離は `holdStart〜holdEnd` の完全接触区間で評価する。
4. 合成リグを使ったPlaywrightテスト `test/motion-quality-measure.spec.ts` を追加する。GPU推論・Jevを呼ばない。

## 計測方法

掌の位置はhand原点ではなく、プロファイルの `palmPoint` をワールド変換した点。

| 項目 | 定義 | 初期合格条件 |
|---|---|---|
| 顔への距離誤差 | 掌中心と「アンカー＋外向きgap」の距離 / W | 保持区間の最大値 <= .03 |
| 合掌位置誤差 | 左右各掌と各目標点の距離 / W | 保持区間の最大値 <= .03 |
| 掌の向き | 顔：掌法線と表面法線の逆方向の角度。合掌：左右の掌法線が逆方向になる角度誤差 | 最大15度 |
| 骨長変化 | 肩→肘、肘→手首の現在長 / レスト長 - 1 の絶対値 | <= 1e-5（一様スケールを補正） |
| 到達不能 | 肩から手首目標までが腕長の範囲外 | 1フレームでもあれば理由を記録しfailed |
| 数値異常 | NaN/Infinity、ほぼゼロ長のquaternion | 0件 |
| 回転の正規化 | abs(length(q)-1) | <= 1e-5 |

合掌の追加検査：胸中心を原点、actor-leftを正として、右肘の横位置が負、左肘が正を保つ。左右掌の順序も逆転させない。肘が中央を超える、または左右前腕の線分間距離が `.04W` 未満なら交差リスクとしてfailed。この線分は肘から `lerp(肘,手首,.8)` までとし、意図的に近づく手首周辺の20%を除く。保持区間だけで評価し、意図的な腕組みには適用しない。これは骨線分による近似でありメッシュ衝突検査とは呼ばない。

角速度は `2*acos(clamp(abs(dot(q0,q1)),0,1))/dt`。角加速度は隣接する角速度の差/dt。qと-qを同じ回転として扱う。これらは初版では前後比較の情報値とし、根拠なく一律の正常値を作らない。

保持区間外のサンプルを接触誤差に混ぜない。保持区間にサンプルが無ければ「未評価」とする。

## 必須テスト

- 正常入力、時刻の逆転、範囲外、未知enum、NaN、欠損ボーン、退化Wを検証。
- 手首は正しい位置だが掌中心だけずれている入力を不合格にする。
- 接触区間外で手が離れていても接触エラーにしない。
- qと-qが交互に現れても角速度0になる。
- アバター全体を回転・移動・一様スケールしても正規化した評価が変わらない。
- `collectPoseMetrics()` 呼び出し前後でボーンの姿勢が変わらない。
