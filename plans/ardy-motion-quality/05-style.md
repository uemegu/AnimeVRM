# タスク05：柔らかく控えめな仕草のプリセット

> 実装済み。現在のコードでは `solveContacts.ts` の elbow-pole bias と接触区間の smootherstep が動作する。この初期版は5点平滑化、指の変更、Qrefへの振幅縮小までは行わない。ここに残る手順は今後の改善案であり、既存の限定実装を未対応扱いして二重実装しない。

読む：`contract.md`、タスク03の `polishClip.ts`、`src/ai/motion/FingerMotion.ts`。

## 目的と範囲

`soft-compact` という任意の演技プリセットを追加する。これは「女性は必ずこの動き」という分類ではなく、このゲームで求める演技の一例。キャラ名や性別だけでは自動適用しない。

初版は動作幅の軽い縮小、回転の小さな揺れの抑制、接触していない手の軽い指曲げだけを実装する。腰の揺れ、脚の内股化、歩行の変更はしない。

## 実装

`style.ts` を追加。接触ソルバーの前に適用する。

`strength=0` またはneutralなら完全なno-op。最初に元データを複製する。

1. 同じVRMへ変換した `Standing Idle.fbx` の先頭姿勢を基準Qrefとして1度取得する。Tポーズを基準にしない。
2. upperArm・lowerArm・handの回転について `Qref.slerp(Qardy, 1-.15*strength)`。頭・胴体・hips・脚はこの縮小対象外。
3. 30fpsの回転列へ、中心を含む5サンプルの重み `[1,2,3,2,1]/9` の対称平滑化を実施する。対象は腕・手首のみ。各qの符号を中心qに合わせ、重み付き和をnormalizeする。長さがほぼ0なら元qを使う。
4. 平滑化した値へのブレンドは最大 `.35*strength`。両端.25秒はsmoothstepで強さを0へ落とし、開始・終了姿勢を維持する。配列端の不足サンプルは端の値で埋める。
5. 非接触の指は既存のopen/fistポーズを同じVRM向けに取得し、各指をopenからfistへ `.12*strength` だけ補間した候補を作る。親指は `.08*strength`。元指姿勢→候補は上記の端フェードを使う。
6. 指を握る・指差し等の明示指定がある場合はそちらを優先する。初版の品質計画にはその指定が無いため、既存のFingerMotionを併用する呼び出し元では指のstyle調整を無効にできる内部オプションを用意する。
7. 最後に接触ソルバーを適用する。接触時の掌位置・向き・open指ポーズを最優先する。

数値は初期値なので、レポートにstyleとstrengthを残す。目視検証なしに「女性らしくなった」「自然になった」と断定しない。

## やらない実装

- 全身のEuler角を一律に小さくする。
- 両手を合わせた後でさらに平滑化し、接触を壊す。
- 全フレームで手首を決まった角度へ曲げる。
- 足やhipsを変え、接地や位置を崩す。
- 再生時にも同じstyleを掛けて、ベイク済みの動作を二重に縮小する。

## 必須テストと確認

`test/motion-quality-style.spec.ts` を追加。

- neutral / strength=0で元データと一致する。
- hips・脚・頭・胴体のトラックが変わらない。
- 合成した回転ノイズの角加速度が減る。q/-q混在で反転しない。
- テスト用の滑らかな挙手の最大回転幅が基準姿勢に対して元の80%以上残る。
- 開始と終了は元姿勢を保持する。
- style＋顔接触／合掌でもタスク01の接触基準を満たす。
- ソルバー後とFBX再読込後の両方で接触を検証する。

```sh
npx tsc --noEmit
npx playwright test --config playwright.ardy.config.ts test/motion-quality-style.spec.ts test/motion-quality-export.spec.ts
```

目視は同じ元モーションに対してstrength=0、.5、1を並べる。生成をやり直した別モーション同士でstyleの効果を比較しない。
