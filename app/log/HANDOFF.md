# HANDOFF 引き継ぎメモ

## 概要
将来的な別リポジトリへの移行を前提としたギャルゲーWebアプリ（`app/` ディレクトリ）の開発引き継ぎメモです。
作業セッション終了時、または重要マイルストーン完了時に常に最新情報へ更新してください。

---

## 現在の実装状況・機能一覧

### 1. ゲームループ & スケジュール管理
- **`ScheduleManager.ts`**: 28日間サイクル（月曜開始・4週間）、フェーズ遷移（朝 ➔ 午前行動 ➔ 昼行動 ➔ 放課後行動 ➔ 夜自室）。
- **進行機能**: ロケーション事前ヒント・キャラ配置、日中強制割り込みイベント、好感度別エンディング判定、1日やり直し（当日朝への完全復元）。
- **`GameHeader.tsx`**: 日付・時間帯・ロケーションバッジ（行動選択時は非表示）、AUTOモード、多言語切替（日英）、ライセンスボタンを統合したフローティングHUD。

### 2. シナリオ & 会話システム
- **`ScenarioEngine.ts` / `ScenarioValidator.ts`**: DOM非依存のHeadlessシナリオステートマシン。Vitestによる単体テスト可能。
- **`DialogueBox.tsx`**: シネマティックグラデーション、Kiwi Maruタイポグラフィ、タイピング演出、AUTO再生（Aキー対応）。
- **`ChoiceBox.tsx`**: スタイリッシュ選択肢UI（スピードライン・ナンバリングバッジ・Thinking Time 10秒カウントダウン・SE連動）。
- **`InterludeOverlay.tsx`**: 4分割スライストランジション幕間演出（「5秒で告白」タイトル固定、多言語対応）。

### 3. 3D描画 & ビジュアル
- **`StageManager.ts` / `StageView.tsx`**: Three.js / VRM / 多層背景描画基盤、全自動リサイズ追従。
- **背景 & ポストプロセス**:
  - 時間帯（ライト・色相・フォグ）とロケーション（多層背景）の直交分離。
  - 高精細AVIF背景（校門・教室・廊下・屋上・中庭・図書室・学食・自室等）。空透過画像のプロシージャル空合成。
  - 完全ポストプロセス（SMAA、Bloom、GodRays、CinematicAnimeShader、ToneMapping）。
- **アバター演出**: Mixamo待機モーション常時ループ、表情クロスフェード補間、自動まばたき、トゥーンシェーダー（影色相シフト・リムライト）。

### 4. オーディオ & リップシンク
- **`SoundManager.ts` / `bgmPresets.ts`**:
  - BGM ID管理体系（`main_theme`, `main_bgm`, `night_room`, `bad_ending`）。
  - 同一BGM連続再生時のシームレス継続、夜自室での音量自動縮小（0.45）、SE再生。
- **`AudioLipSync.ts`**: Web Audio API + AudioWorklet + WebAssembly による高精度母音解析・VRMモーフ連動。

### 5. プリロード & ローディングシステム
- **`preloadTargets.ts`**: プリロード対象のURL・表示ラベル・種別を一元管理する設定モジュール。
- **`generate-preload-manifest.js` & Viteプラグイン**:
  - `npm run dev` および `npm run build` 時に `public/` 内の実ファイルサイズ（バイト数）を走査し、`preloadManifest.json`（全14アイテム、約164.6MB）を自動生成。
  - 対象: ヒロイン3人（制服・制服リュック付き・私服計9体）、先生モデル、主要BGM2曲、リップシンクWASM/Worklet。
- **`AssetPreloader.ts`**: マニフェストから正確なサイズを読み込みストリーミングロード。
- **`LoadingScreen.tsx`**: 自動計算された容量（「約 165 MB」）およびリアルタイム進捗を表示。STARTボタン押下によるAudioContext安全アンロック。
- **幕間オンデマンドロード**: 待機モーション、個別ロケーション背景、ボイスは幕間スライスの画面被覆中に非同期ロード。

### 6. セーブ & UIモーダル
- **`SaveService.ts`**: localStorage へのセーブ・ロード、当日朝スナップショット管理、破損時フォールバック。
- **`ActionSelectModal.tsx`**: 学校俯瞰マップ連動、時間帯別カラー連動、ヒロイン遭遇バッジ、ホバー時立ち絵＆INFOバナーポップアップ、行動カード。
- **`NightRoomView.tsx`**: 夜の自室コマンドメニュー（就寝・セーブ・ロード・やり直し）、好感度ステータスパネル。
- **`LicenseModal.tsx` / `generate-licenses.js`**: `package-lock.json`（18パッケージ）と外部アセットクレジットを自動収集・表示するライセンスモーダル。
- **`ConfirmModal.tsx`**: 共通YES/NO確認ダイアログ（`window.alert` 完全廃止）。

## 基本ゲーム進行
- **期間**: 28日間（月曜開始・4週間） / 28日目エンディング
- **1日のサイクル**:
  1. **朝**: 登校等の固定イベント
  2. **午前 / 昼 / 放課後**: 行動ターン（学校マップから場所選択、会話・選択肢）
  3. **夜**: 自室（セーブ / ロード / 1日やり直し / 就寝で翌朝へ）
  - ※未遭遇キャラ救済等の日中強制割り込みイベントあり

## 設計上の留意事項・制約
- **他リポジトリ移行前提**: ルートの既存ファイルへの直接依存を作らず、`app/` 配下で完結する疎結合設計を徹底。
- **UIデザイン規則**:
  - 原則として **白（`#ffffff`、明るい半透明ガラス等）を基調** としたライトテーマで設計（ダークテーマ勝手適用禁止）。
  - 明示的指示のない限り **絵文字（📅, 📍, 💡等）のUI使用禁止**。SVGアイコンやタイポグラフィを使用。
  - UI変更時は自動テスト前に画面キャプチャを提示してユーザー確認・承認を得ること（デザイン先行確認原則）。
- **シナリオ単体テスト容易性**: Headless Engine（`ScenarioEngine.ts`）により、DOM/WebGL非依存で分岐・フラグをVitest単体テスト可能に保つ。
- **多言語（i18n）統合**: シナリオファイル内で `{ ja, en }` を統合保持。
- **作業ログ義務**: app開発作業時は `app/log/YYYY-MM-DD.md` に作業ログを記録し、本引き継ぎメモを最新状態に保つこと。
