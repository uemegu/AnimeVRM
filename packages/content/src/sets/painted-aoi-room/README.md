# 簡易3Dのアオイの部屋（壁ごとの1枚絵 + 立体の家具）

一枚絵の「アオイの部屋」（`assets/textures/aoi_room_far.avif`）を、座れて四方から撮れるようにした撮影用セット。ベッドの縁に座る・勉強机で頬杖をつく場面のために作った。窓の外の空は絵に描かず透過にし、ビューアの空（SkyBackground）を `sky-only.png` 経由で後ろに描く。

- 場所: `aoi_house`（`assets/studio/locations.json` の組み込み3D背景 `builtin:painted-aoi-room`）。元の一枚絵は `aoi_house_2d` に残してある
- シナリオ: `assets/scenarios/demo/painted_aoi_room/`（正面・左右・後ろ、俯瞰、立ち、ベッド・机の席）
- 素材: `assets/textures/painted-aoi-room/*.avif`。生成指示は `PROMPTS.md`

## 構成

- 寸法・家具の配置は `layout.ts` に集約（3.6m × 3.6m、天井2.4m。約8畳）。奥（-z）がベランダの掃き出し窓、左の壁沿いにベッド、右の壁沿いに勉強机と本棚。
- 壁4面: 面全体を1枚で生成（3:2）。窓の壁は空の部分だけ透過。家具は描かせず、壁の飾り（写真のワイヤーネット、額、棚、時計、クローゼット、ドア）だけを描いている。
- 床: 木のフローリングのタイル（1.8m 四方で繰り返し）。ラグ: 毛足のタイルを、ふちを毛羽立たせた角丸の切り抜き（CanvasTexture）で切る。
- ベッド: 箱の側面・足元・上面にそれぞれの絵（`bed-side`・`bed-foot`・`bed-top`。掛け布団の垂れまでで、黄色いひざ掛けは描かない）。側面と足元は掛け布団の垂れが透過の切り抜きなので、中に少し小さい白い箱を入れてある。枕・花のクッションは立体、柴犬のぬいぐるみは切り抜きの板。
- ひざ掛け: 平らに描いた1枚（`throw`、短い辺に房飾り）を、格子の布としてベッドの足側に掛け、部屋側の横と足元へ角を丸めて垂らす（`throwBlanket`。垂れた所に波を付ける）。生成した黄色が元絵より強いので、色を掛けて落ち着かせている。
- ローテーブル: 天板は真上から描いた絵（`table-top`、角丸の長円で切り抜き）、天板の厚み・脚は立体。天板の絵は木目と平らなランナーだけで、カップ・花瓶・本のような立体であるべき物は描かない（真上からの絵だと横から見て潰れる）。
- 本棚: 正面だけ絵（`bookshelf`）、側面は白木の無地。机・椅子・ナイトテーブル・ヘッドボード・ローテーブルの縁は、生成した木目のタイル（`wood`、0.6m 四方）を実寸のUVで貼る（`woodBox`。木目は各面の長い辺の向き）。ライト・座布団は単色の立体。
- 影: 場所の `light` で窓から差す日（光の来る向き `(0.8, 1.3, -2.0)`）と床の影を付け、家具・ひざ掛け・座布団に影の目印（`castShadows`）を付けている。絵（壁・床・ベッドや本棚の絵の面）は光が描き込まれているのでセル調の明暗を外し（`userData.cel = false`）、木の立体や枕などだけ面の向きで明暗が付く。

## 席

| 席 | 位置（場所の座標） | モーション | メモ |
| --- | --- | --- | --- |
| `aoi_bed`（ベッドの縁） | `[-1.15, 0, -0.85]`、向き +x | `pose_stretch_legs` | 縁から12cmほど奥に腰を置く（手前だと空気椅子になる）。ローテーブルの方を向く。正面低めから撮るとスカートの中が見えるので、足元側の斜め上から撮る |
| `aoi_desk`（勉強机） | `[0.91, 0, -0.76]`、向き +x（壁） | `desk_chin_rest` | 椅子に座って机に両肘をつく。腰から机の手前の縁まで 0.13m。顔は机の窓側の端から撮る。後ろ姿なら引きの `wide` |

場所の原点は部屋の座標 `(0.2, 0, -0.9)`（ローテーブルの手前の空いた床）。立ち位置（±0.45m）と会話のカメラ（2m 以内）が部屋に収まるよう、`stage.camera` の距離を短くしてある。

## 撮れる範囲と制約

- 原点付近から正面・左右・後ろ、俯瞰を確認済み。壁は平面の絵なので、壁に近づいて斜めから見ると額や棚の厚みはない。
- ローテーブルの前の床（座布団）に座るモーションはない（`chin_rest` は椅子の高さ、`pose_stretch_legs` はベンチの高さ）。床に座らせるには正座・横座りなどのモーションが別に要る。
- 机の席はカメラを置ける場所が狭い（机と壁の間）。寄りは机の窓側の端から。

## desk_chin_rest.fbx

`chin_rest.fbx`（座面のない中腰の頬杖）を `scripts/blender/make_desk_chin_rest.py` で作り直したもの。元の揺れ・頭の傾き・頬の右手は残し、毎フレーム、腰を座面の高さ（0.62m）に下げて上半身を12度前へ倒し、太ももを水平・すねを垂直にし、右肘・左前腕を机（0.66m）の上へ置く（2関節のIK）。前腕の高さは机から 4.5cm 上で狙う。椅子 0.45m・机 0.66m・腰から机の縁 0.13m を前提にしているので、ほかの机で使うときは席の位置をこれに合わせる。

Blender の FBX 書き出しは、書き出す瞬間の姿勢をボーンの基準（Lcl）として書く。エンジンは基準をTポーズとして変換するので、範囲外のフレームに基準姿勢のキーを置き、そのフレームで書き出している。

机を 0.72m にしていたときは、上半身が起きているため肩が机の縁より体側にあり、二の腕の長さでは肘が肩の真下（机の縁の手前）までしか届かず、肘が机の縁に埋まった。肩と机の高さの差を広げると肘を前へ出せるので、机を 0.66m に下げ、椅子を机へ寄せている。
