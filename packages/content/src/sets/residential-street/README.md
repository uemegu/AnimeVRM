# 住宅街（簡易3D）

`builtin:residential-street` / 場所 `residential_street` / デモ `demo/residential_street`。
2階建ての家・ブロック塀・電柱が並ぶ日本の住宅街の、長い直線道路。

元絵はない。家の正面2種・側面・路面・ブロック塀を、運動場の校舎の絵を絵柄の参照にして新しく描いた（[PROMPTS.md](./PROMPTS.md)）。

## 座標と寸法（`layout.ts`）

- 道路は z 方向にまっすぐ、北が -z。原点は道路の中央。北へ 330m、南へ 70m。
- 路面の幅 5.5m、両脇に側溝 0.45m、その外にブロック塀（高さ 1.3m）。
- 区画は間口 13m で片側 30。5区画ごとに交差する道（幅 6m）。原点のすぐ南（z=6）に交差点がある。
- 家は間口 9.5m × 奥行 8m、軒高 6.2m、切妻屋根。塀から 2.5m 下げて置く。
- 電柱は東側の側溝の上に 26m おき。
- 東西 62m と道の両端に、遠景の樹木帯。カメラの `far` は 420。

## 素材の分担

| 部分 | 作り |
| --- | --- |
| 家 | 箱の道路側に正面の絵（2種を交互）、ほか3面に側面の絵。屋根は実形状（瓦は CanvasTexture、3色） |
| 路面・交差する道 | アスファルトの繰り返し（4m）。白線と停止線は同じ高さの板を手前に描かせる |
| 塀 | ブロックの繰り返し（2.4m × 1.3m）。門の開口と門柱は実形状 |
| 庭木 | 運動場の `tree.avif` を3枚の固定の交差板で |
| 遠景 | 運動場の `far-tree-belt.avif` |

絵に光が描いてある面（家・路面・塀）はセル調の明暗を外している（`userData.cel = false`）。影を落とすのは門柱・電柱・庭木。

## 確認した範囲と制約

- 道路の上から前後左右、家の角を斜めから、道の奥から振り返る向き、俯瞰、人物を置いた会話カメラを撮って確認した。
- 家の裏（道路から 14m より外）は無地の地面だけ。俯瞰では空き地が見える。道路の高さからは家と塀で隠れる。
- 門の中へ入る・庭に立つ・家に入ることは想定していない。塀に笠木はない。
- サムネイル: `assets/textures/residential-street/thumb.avif`（デモの `forward` を撮ったもの）。
