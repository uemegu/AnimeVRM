# 商店街（簡易3D）

`builtin:shopping-street` / 場所 `shopping_street_3d`。
運動場・中庭と同じ、UV を貼った建物と固定の交差板植栽で構成する。
元の `town2_far.avif` を参照して店舗立面を生成し、石壁、蔦、花、店内の暖色光を維持する。

- 左右各7棟と前後各3棟、計20棟。幅7.2m、奥行7m、高さ10.8m、屋根高さ1.5m。
- 前面は書店・花屋・ギャラリーの立面、側面と背面は上階の窓と石造りの下階。
- 屋根、煙突、ひさし、バルコニー手すり、両面の吊り看板、街灯、ベンチ、書籍台、A型看板、花箱は実形状。
- 花と樹木は60度ずつ交差した3枚の固定板。カメラへ追従する処理はない。
- 地面は連続した石畳と樹木の足元の固定影。遠景の樹木帯は四方向に配置。
- 描き込まれた光を保つため MeshBasicMaterial を使用。建物の光と葉の影は素材に含まれ、動的な建物の影・室内への入店は対象外。
- 共有マテリアルの静的形状をまとめ、退出時にテクスチャ・形状・マテリアルを一度ずつ解放する。

生成指示は [PROMPTS.md](./PROMPTS.md)。使用素材は `assets/textures/shopping-street/`。

## 方向確認

デモ `demo/shopping_street` は立ち位置 `[0, 1.65, 3]` を変えず、正面、左90度、右90度、後方180度を撮る。
店先の斜め方向、通りの奥からの逆方向、建物の屋根と厚みの俯瞰、人物との会話も含む。

```sh
npm run validate
npm run typecheck
npm run shot -- demo/shopping_street --no-dialogue --no-hud
```

元の2D場所 `shopping_street` と元画像は変更しない。
