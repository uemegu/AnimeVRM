# 簡易3Dの観覧車のゴンドラ（立体のゴンドラと観覧車 + 360度のパノラマ）

夕暮れの観覧車のゴンドラの中で、向かい合わせのベンチに座って話す場面のための撮影用セット。元絵は `tmp/夕暮れの観覧車ゴンドラから望む遊園地.png`（作業用の控えは `scratch/gondola/reference.png`）。ゴンドラと観覧車は立体で組み、窓の外の遊園地・湾・街並みは周囲を囲む360度のパノラマの絵で見せる。空は絵に描かず透過にし、ビューアの空（SkyBackground）を `sky-only.png` 経由で後ろに描く。

- 場所: `ferris_gondola`（`assets/studio/locations.json` の組み込み3D背景 `builtin:painted-gondola`）
- シナリオ: `assets/scenarios/demo/painted_gondola/`（正面・左右・後ろ、元絵と同じ構図 `reference_view`（サムネイル）、手すり `rail_close`、扉 `door`、見下ろし・見上げ、俯瞰、各ベンチの席、横からの2ショット、立ち）
- 素材: `assets/textures/painted-gondola/*.avif`。生成指示は `PROMPTS.md`

## 構成

- 寸法・配置は `layout.ts` に集約。床が y=0、ゴンドラの中心が原点。元絵と同じく正面（-z）が夕日の沈む海で、観覧車の本体は後ろ（+z）にある。内寸 2.0m × 2.4m、天井 2.1m。
- ゴンドラ（`PaintedGondola.ts`）: ステンレスの壁は腰の高さまでと窓の上だけで、四方は窓（ガラスは置かず、開口のまま）。四隅を斜めにつなぐ柱（角の面取り。壁沿いに 0.2m ずつ）・窓の上下の枠・横の窓の中桟・手すり・ベンチ（座面と背もたれは紺のビニールのクッション）を立体で作る。ステンレス・座面・床は継ぎ目のないタイルを実寸のUVで貼る。前の窓の上に換気口。
- 扉（元絵にはないが実物に合わせて足した）: 右（+x）の横の壁の中ほど、幅 0.84m、床から窓の上まで。内側へ張り出した戸枠の柱2本、腰までのステンレスの戸板と上の窓の枠、戸板の周りの合わせ目、蝶番（+z 側）、取っ手（-z 側）、床の敷居。ガラスはほかの窓と同じく置かない。開かない。
- 手すり（元絵どおり）: 壁と同じステンレスの管。横の窓の手前 7cm を通り、両端は斜めの角の柱の内側の面に丸い座金で突き当て、真ん中は横の窓の中桟に留め金具（管を巻く輪と短い腕）で留める。扉のある右側は、角の柱から戸枠の柱までの2本に分け、扉には短い腕で留めた握り棒を付ける。
- 観覧車（`Wheel.ts`）: 半径 40m。ゴンドラは頂上から 22 度 -x 側に下りた位置に吊られ、観覧車の面は背面の 2m 後ろ（z=3.2）。外輪・内輪を前後2重にしたトラスのリム、ハブへ伸びるトラスのスポーク16本、奥側のA字の脚、ほかの31台のゴンドラ（色違いの角丸の箱と窓の帯）、電球（加算の光の点）。鉄骨はすべて1つの InstancedMesh。
- 景色（`Panorama.ts`）: 半径 110m の円筒に、空を透過にした360度のパノラマ（4枚の90度のタイル `pano-0..3` = 正面・右・後ろ・左）。円筒図法で縦横の画素の大きさが同じなので、円筒の高さは幅から決まる。水平線は画像の上から 248/1024 で、目の高さ（y=1.25）に合わせる。真下は地面の円盤（`ground.avif`、上から見た遊園地のタイル、60m 四方で繰り返し）。
- 水面（`Panorama.ts` のシェーダー）: 手前の湾と右奥の湾は絵ではなく、画素ごとに地面の高さの水面として描き直す。拡大しても波がくっきりし、ゆっくり動く。映り込みはパノラマの絵そのものを対岸の水際で上下に折り返して波で揺らしたもの（対岸の明かりの光の筋になる）。太陽の光の道は正面やや右（`SUN`）。どこが水かは `sea-mask.avif`（R = 水、G = その列の対岸の水際の行）で決める。運河や小さな池は絵のまま。
- 明かりのにじみ: パノラマの明るく暖かい色の画素（街・遊園地の電飾）を `LIGHT_GLOW` 倍に持ち上げてブルームのしきい値を超えさせ、場所の `stage.camera.bloom`（強さ 0.2）でにじませる。
- 光と影: 場所の `light` で正面左上からの西日（`(-0.35, 0.55, -1.0)`）と床の影を付ける。影の目印（`castShadows`）は角の柱・窓枠・ベンチ・手すりだけ。壁に付けると影がゴンドラの外の宙に落ちる。
- 夕方の画作り: 場所の `stage.postProcessing` で光条とレンズフレアを切り、遠景（空）の明るさを 0.8 にしている。ステンレスの絵の照り返しが白飛びしないよう、素材の色で少し暗くしてある（タイル自体も `scripts/painted-gondola/soften.py` で縞を弱めたもの）。

## パノラマの作り方

1. 正面（`pano-F`）を1枚生成する（1536×1024、水平線を上から24%、空は透過、遊園地を見下ろし、夕日の照り返しの海）。
2. 左右へ3枚ずつ継ぎ足す（`R1..R3`、`L1..L3`）。前の絵の端の 512px を下書き（`scripts/painted-gondola/draft.py`、残りは灰色）に入れ、「その部分を変えずに続きを描く」と指示する。最後に背面の `C` で `R3` と `L3` の間を埋める。
3. `scripts/painted-gondola/stitch.py` で 8192px の帯に並べ（重なりは中ほど 384px でクロスフェード）、4枚に切る。`avifenc --qalpha 100` で変換。

並び（帯の列 c は向き `c/8192*360-45` 度。0 度が正面 -z、右回り）: F が 256 から、R1・R2・R3 が 1024px ずつ右へ、L1・L2・L3 が左へ、C が 4352 から。

## 席

| 席 | 位置 | 向き | メモ |
| --- | --- | --- | --- |
| `gondola_front_left` / `gondola_front_right` | `[∓0.42, 0, -0.9]` | +z（後ろのベンチの方） | 背景は前の窓の夕日の海と遊園地。いちばんの見せ場 |
| `gondola_back_left` / `gondola_back_right` | `[∓0.42, 0, 0.9]` | -z | 背景は後ろの窓の観覧車の鉄骨と空 |

モーションは `pose_sit_seat`（背筋を伸ばし、膝に手を置いて座る）。座面の高さ 0.5m。膝から下がまっすぐ下りるので、腰（ルート）は座面の縁から 0.2m 奥に置く。これより奥にすると脛がベンチの台座にめり込む。左右は元絵の向き（正面を見て左が -x）。

立ち位置は通路の中央（`left`/`center`/`right` = x ±0.45）。狭いので会話のカメラは距離 0.9〜1.15m、画角 55 度にしてある。

## 水のマスクの作り方

`scripts/painted-gondola/sea-mask.py`。パノラマのタイルを PNG に戻した（`avifdec pano-N.avif pano-N.png`）フォルダで実行し、出た `sea-mask.png` を `avifenc -l`（ロスレス。G は行番号なので劣化させない）で `sea-mask.avif` にする。青く滑らかな画素を水とし、水に左右を挟まれた明るい画素（絵の光の筋）と太陽の光の道も水に含める。落下塔は枠を決めて色で抜く。パノラマを描き直したら作り直すこと。

## 撮れる範囲と制約

- ゴンドラの中から四方・見下ろし・見上げ、俯瞰を確認済み。外からゴンドラを撮ることは想定していない（外装は箱のまま、ガラスもない）。
- パノラマは 110m 先の円筒の絵なので、ゴンドラの中で動く程度では視差はほぼない（遠景なので不自然ではない）。8192px で360度なので、望遠で窓の外だけを大きく撮ると絵がぼやける。画角 40 度より狭くしないこと。
- 空はビューアの空（画面に貼る）なので、向きを変えても太陽・雲の位置は変わらない。夕日の照り返しはパノラマの正面の海に描いてある。
- 観覧車は回らない（ゴンドラは止まった位置）。夕方以外の時間帯でも絵は夕暮れのまま。
