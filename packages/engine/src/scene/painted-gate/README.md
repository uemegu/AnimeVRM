# 簡易3Dの校門（下書きの上に描いた絵をカメラから投影）

校門の前の歩道にアバターが立ち、開いた門の奥に構内の広場・守衛室・校舎が見える撮影用セット。景色全体を基準カメラから見た1枚絵として描き、同じカメラから下書きの箱（地面・塀・門柱・門扉・守衛室・奥の面）へ投影する（マットペイントのカメラ投影）。カメラが少し動くと箱の奥行きに応じて視差が出る。空は絵に描かず透過にし、ビューアの空（SkyBackground）を後ろに描く。

- 場所: `painted_gate`（`assets/studio/locations.json` の組み込み3D背景 `builtin:painted-gate`）
- シナリオ: `assets/scenarios/demo/painted_gate/`（朝・昼・放課後）
- 素材: `assets/textures/painted-gate/`
  - `gate.avif`: 門の層（塀・門柱・門扉）。全体の絵を門の層のマスクで切り抜き、門扉の格子の間も透明にしたもの（奥は `scene.avif` が見える）
  - `guardhouse.avif`: 守衛室の層。門・塀を消した絵を守衛室のマスクで切り抜いたもの
  - `scene.avif`: 奥の層。門・塀と守衛室を消し、隠れていた地面・並木・校舎を描き足したもの
  - `tile-*.avif`: 絵が届かない面に敷く継ぎ目なしの素材（舗装・道路・塀・門柱の石・校舎の外壁）
  - `far-campus.avif`・`far-houses.avif`: 四方の遠景（北は構内、南・東・西は家並み）

## 構成

- 寸法・基準カメラ・撮影例は `layout.ts` に集約。アバターは原点、塀の面は z=-3。
- 投影は `PaintedGate.ts` の `projectedMaterial`（MeshBasicMaterial のシェーダーで UV の代わりに基準カメラの射影座標を使う）。
- 手前の物（門・塀、守衛室）を別の層にしているので、横に動くと後ろに隠れていた景色が見える。同じ絵に描いたままだと、後ろの面にもう1つ同じ物が映る（守衛室が二重に見えた原因）。手前に物を足すときも層を分けること。

## 四方と空

どの向きから撮っても破綻しないように、絵の外を次のように埋めている。

- 絵の範囲外・基準カメラから見て裏向きの面（塀の裏など）・絵の透明部分は、`projectedMaterial` がワールド座標で `tile-*.avif` を敷く。絵の枠の近くは両方をぼかしてつなぐ。
- 奥の校舎は絵の範囲の外も `tile-facade.avif` で構内の端まで続く（外壁の上は透明で空が見える）。
- 地面は基準カメラから遠いほど絵が奥行き方向に引き伸ばされるので、`GROUND_PAINTING_FADE` の距離で舗装の素材に切り替える。
- 門の前は歩道、その先に車道と向かいの歩道（`ROAD`）。外周は `FAR` の位置に遠景の一枚絵を立てる（家並みは横に繰り返す）。ビューアの描画距離（100m）に収めること。
- 空はドーム（`userData.setSky`）。ビューアは時間帯で変わる自前の空を描くので、StageManager がドームを隠す。Studio の俯瞰表示では見える。

## 絵の作り方

1. `node scripts/painted-gate-blockout.ts <出力先>` で下書きとマスクを出す（`blockout.png` 全体、`blockout-scene.png` 門の層なし、`blockout-back.png` 門と守衛室なし、`gate-mask.png`、`guardhouse-mask.png`）。
2. codex CLI の画像生成で、`blockout.png` の上に「輪郭の位置を動かさずに」全体の絵を描かせる（空は透明）。
3. 同じく、全体の絵と `blockout-scene.png` から門・塀を消した絵を、さらにそれと `blockout-back.png` から守衛室も消した絵を描かせる。
4. 全体の絵に `gate-mask.png` を、門・塀を消した絵に `guardhouse-mask.png` をアルファとして入れて `gate.avif`・`guardhouse.avif` に、両方消した絵を `scene.avif` にする（`avifenc --qalpha 100`）。
5. `gate.avif` の門扉は、格子の間（上下の横桟の間で格子でない列と、下の横桟の下の地面）のアルファを 0 にする。格子は縦にまっすぐ描かれているので、門扉の中ほどの行の明るさを列ごとに平均し、暗い列を格子とみなせば切り抜ける。マスクのままだと格子の間に基準カメラから見た奥の景色が貼り付き、カメラが動くと奥とずれる。

`layout.ts` の箱やカメラを変えたら、下書きから描き直すこと。

## 制約

- 描き込んだ絵は基準カメラ（歩道の目線、門から 7.5m 手前）から見た範囲だけ。それ以外の向きは素材と遠景の一枚絵なので、見た目は簡素になる。会話の見せ場は `GATE_SHOTS` 程度の範囲で撮ること。
- 並木と校舎は奥の1枚の面（z=-30）に描いてあるので、並木の立体感はなく、横や上から見ると板だと分かる。
- 光と影は絵に描き込んであるので、時間帯を変えても影の向きは朝のまま。キャラを照らす光の向きと地面に落ちるキャラの影は、場所の設定（`locations.json` の `light`）で絵の光（左手前から差す朝日）に合わせている。
