# 簡易3Dの夏祭り（屋台の通り + 川 + 花火）

屋台が両側に並ぶ通りにアバターが立ち、通りの先の手すりの向こうに川と対岸の灯りが見える撮影用セット。夜の夏祭り専用で、空に花火が上がり、屋台の灯りと花火の光がキャラを照らす。参考にした元の一枚絵は `night-festival-far.avif`（場所 `night_festival`）。

- 場所: `painted_festival`（`assets/studio/locations.json` の組み込み3D背景 `builtin:painted-festival`）
- シナリオ: `assets/scenarios/demo/painted_festival/`
- 素材: `assets/textures/painted-festival/`（すべて codex CLI の画像生成で描いたもの）
  - `stall-<種類>.avif`: 屋台の正面の立面図（たこ焼・金魚すくい・かき氷・りんご飴・焼そば・お面）
  - `far-bank.avif`: 川の対岸の遠景（下端が水際、横に繰り返す）。`far-town.avif`: 陸側の町並み
  - `tile-paving.avif`: 石畳（地面・護岸・手すりの柱に使う）。`banner.avif`: 「夏祭り」ののぼりの柱
- サムネイル: `assets/textures/painted-classroom/thumb-festival.avif`

## 構成

- 寸法・撮影例は `layout.ts` に集約。アバターは原点、屋台の正面は x=±2.7、手すりは z=-6.2、川面は y=-1.8、対岸は z=-46。
- 屋台（`Stalls.ts`）: 柱・縞の屋根・垂れ幕・カウンター・奥の壁を実際の形で組み、正面の絵を3つの帯（看板・奥の壁・カウンターの前板）に切って貼る。帯の境目は絵ごとに少しずれるので `STALL_BANDS` で合わせる。横はカウンターの高さまでの幕だけにして、通りの斜めから奥の商品が見えるようにしている。
- 空は時間帯の空を使わず、セット自身の夜空（`NightSky.ts`：星・月・花火に照らされる薄い煙）を描く。時間帯は `night` を使う。
- 川（`River.ts`）: 視線と水面の交点ごとに、さざ波で曲げた反射を対岸の絵・夜空・月・花火に当てて色を決める。加えて、対岸の灯りの真下に縦の光の帯を手前まで伸ばす（実際の反射より誇張した、元の絵の見た目）。
- 花火（`Fireworks.ts`）: 打ち上げ・開花・尾を引いて消えるまでを GPU で計算する。種類は菊・牡丹・輪・柳・色変わり。乱数は固定の種から作るので、撮影すると毎回同じ順で上がる。
- 外周は対岸の絵（川側）と町並みの絵（陸側の3方）。ビューアの描画距離（100m）に収めること。

## 光

セットの絵と形はすべて光の影響を受けない素材で、灯りは描き込みと次の仕掛けで表す。

- 地面・護岸・柱: 屋台の前・提灯の下・行灯の周りに暖色の光だまりを描く（`lights.ts` の `WARM_POOLS`）。
- 花火の光: 開いた花火の明るさと色を毎フレーム合計し（`uFlash`）、地面・屋根・看板・夜空の煙・川面に足す。
- キャラ: 実際のライトで照らす。近くの屋台4軒の暖色の点光源と提灯の点光源、花火の方向から花火の色で光る平行光（開いた瞬間に強く、すぐ消える）。月明かりと環境光は場所の設定（`locations.json` の `light`。色・強さ・環境光もここで上書きしている）。

## 制約

- 夜専用。絵に夜の灯りが描き込んであり、空もセットが描くので、時間帯を昼や夕方にしても夜のまま（キャラの色だけ変わる）。
- 花火は常に上がり続け、止める設定はない。キャラを照らす花火の光は平行光なので、屋台の屋根の下でも同じように当たる（影で遮られない）。
- 通りの奥（z=15 より先）と屋台の裏は石畳が続くだけで簡素。会話の見せ場は `FESTIVAL_SHOTS` 程度の範囲で撮ること。
- 屋台の奥の壁は1枚の絵なので、真横に近い角度から見ると平らだと分かる。

## 絵の作り方

1. 屋台は、看板・奥の壁・カウンターの前板の3つの帯を描いた正方形の下書き（帯の高さは `STALL` の寸法どおり）を codex CLI に渡し、「夜の夏祭りの○○の屋台の正面を、帯の位置を動かさずに真正面の立面図で」描かせる。元の夏祭りの絵を絵柄の参照に渡す。
2. 対岸は、水際・町並み・山並みの位置を描いた 3:1 の下書きを渡し、空を透明に、下端を水際にして描かせる。
3. 描けたら帯の境目を測って `STALL_BANDS` を直す。透過のある絵は `avifenc --qalpha 100` で変換する。
