# 簡易3Dの教室（面ごとの1枚絵 + 机のアクスタ）

床・壁・天井を面ごとに生成した1枚絵で貼り、机と椅子を段ごとの透過画像（アクスタ）として並べた撮影用セット。窓の外の空は絵に描かず透過にし、ビューアの空（SkyBackground）を透明な背景画像 `sky-only.png` 経由で後ろに描く。ライト・ポストプロセスはシーンプリセット（`day_school`）のまま使い、ステージ独自の設定は持たない。自由に歩き回る用途ではなく、会話シナリオのカメラワーク（教室後方からの引き・2ショット・通路からの切り返し）に耐えることが目的。

- 場所: `classroom`（生徒の席のあたり）と `classroom_podium`（教壇。先生が教卓の後ろに立つ）。どちらも `assets/studio/locations.json` の組み込み3D背景 `builtin:painted-classroom`。Studio のシーン設定で見え方を確認できる
- シナリオ: `assets/scenarios/demo/painted_classroom/`、教壇の確認は `assets/scenarios/demo/painted_classroom_podium/`
- 素材: `assets/textures/painted-classroom/*.avif`

## 構成

- 寸法・机の配置・基準カメラは `layout.ts` に集約（幅7m×奥行10m×天井3m、机は左右3列ずつ×6段）。
- 床・天井・正面/左/右の壁: 面全体を1枚で生成（繰り返し模様にしない。光の当たり方が面ごとに自然になるように）。
- 机: 段ごとに1枚（`desk-row-1..6.avif`）。段ごとに遠近が違うので使い回さない。
- 教壇: 黒板の前の高さ20cmの木の段（`layout.ts` の `PLATFORM`。板目は CanvasTexture）。棚に掛からない幅にしてある。
- 教卓: `podium.avif` を天板・天板の小口・本体の帯に分けて、教卓の形の立体の各面に貼る（側面・裏は無地の板）。教壇から撮っても天板の奥行きが出る。
- 棚: 単体のアクスタ。
- 床に机の接地影を薄く置く（生成した床には家具の影を描いていないため）。

## 机の段の作り方

生成した絵の遠近をセットの遠近と一致させるため、下書きの上に描かせて、同じカメラから投影し直す。下書きのページ（`*-blockout.html`・`blockout.ts`）と確認ページは、2026-09-27 に旧ルートと一緒に消した。作り直すときはコミット `a582c47` 時点のものを戻して使う。

1. `/AnimeVRM/painted-classroom-blockout.html?row=N` が、灰色の箱で作った N 段目だけを段専用カメラ（基準カメラを `setViewOffset` でその段に切り出したもの、3:1）で描画する。
2. その画像を下書きとして、codex CLI の画像生成で「位置・遠近はそのままに本物の机と椅子として描き直し、背景は透過」で生成。
3. `rowGeometry()` が段の板（椅子の脚元から天板の奥端へ傾いた面）を段専用カメラの視野いっぱいに作り、そのカメラから絵を投影する UV を付ける。

基準カメラ付近から撮る限り絵の遠近とセットが一致する。`layout.ts` の机の配置やカメラを変えたら、下書きから机の段を作り直すこと。

## 教壇（classroom_podium）

先生の立ち位置 `TEACHER_POSITION`（教卓の後ろ、教壇の上）を原点にした場所。環境の位置 `(0, -0.2, 8.45)` で、教壇の上面が y=0 になる。立ち位置は中央が教卓の後ろ、左右（±0.95m）が教卓の横。構図は生徒の席から見上げる距離に広げてある（`stage.camera`）。

撮れるのは生徒側から教壇を見る向き（正面・斜め・左右の壁）。先生の後ろから生徒側を見る切り返しは、机の段が後ろからの絵の投影なので向きが逆に見え、後ろの壁も無地のため使えない。
