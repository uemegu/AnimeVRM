# 運動場・中庭の共有マップ（簡易3D）

`app` の学校地図 `assets/assets/backgrounds/school_aerial.avif` を参考にした撮影用セット。
校門のカメラ投影、夏祭りの「立体に正面の絵を貼る」構成を参考に、広い運動場を複数方向から撮れるよう、立体・正面の絵・切り抜きの木・外周の遠景を組み合わせる。

- 場所：`painted_ground` と既存の `courtyard`、組み込み背景：どちらも `builtin:painted-ground`
- デモ：`assets/scenarios/demo/painted_ground/scenario.json`（校舎、トラック、中庭、校門、駐輪場、俯瞰、会話、放課後の8カット）
- 中庭デモ：`assets/scenarios/demo/painted_courtyard/scenario.json`（対称の植栽、運動場への入口、校舎入口、駐輪場、会話、俯瞰、既定の会話カメラの7カット）
- 配置と撮影例：`layout.ts`。単位は m、原点は運動場の東側のサイドライン。
- 素材：`assets/textures/painted-ground/`。土・木・中央の針葉樹・時計付き校舎・遠方の樹木帯は内蔵 imagegen で作成し、AVIF に変換。側面は既存の校門の外壁素材から3階分を切り出し、正面とともに窓を室内が見える表現へ編集したもの。
- 校門の `tile-paving.avif` を共用。Pages の素材収集にも登録。住宅の遠景素材は使わない。

## 地図からの位置関係

地図の上を便宜上北（-z）、右を東（+x）とする。実際の方角や正確な寸法が地図に記されているわけではない。

| 方向 | 運動場から見えるもの |
| --- | --- |
| 北〜北東 | 3階建ての時計付き校舎、屋上フェンス、校舎前の並木 |
| 東 | 石の囲い付きの中庭、通路、その向こうの植栽と屋根付き駐輪場 |
| 北東〜東奥 | 右側の校舎棟と丸屋根の体育館 |
| 南〜南東 | 校門の門柱、守衛室、囲い付きの並木、道路と奥の樹木帯 |
| 西〜北西 | 防球ネット、低い植栽と並木、通路、その奥の樹木帯 |

運動場は4レーンの土のトラック、サッカーの白線、前後のゴールと網、防球フェンスで構成する。東のネット沿い（`layout.ts` の `BENCH`）に、運動場向きの木の座面と鉄脚のベンチを置く。キャラを座らせるときはこの位置と向きに合わせる（アオイ d08）。中庭との間にも背の高いネットを設け、原点付近に通路を空ける。

中庭の木は舗装面から直接生やさず、角を丸めた長方形の植栽、中央の円形花壇、通路沿いの細長い植栽に分ける。時計と中央の花壇を結ぶ x=31 の軸に、左右の花壇・並木を同じ間隔・高さで対称に並べる。石の囲いは高さ36cmの中空の立体で、その内側に14cmの土面と低木・木を置く。低木は縁から余白を取って並べ、囲いを隠さない。駐輪場は中庭の東側の植栽越しに置き、校舎の正面と並行する長い銀色の片流れ屋根、柱、自転車、舗装と区画線を作る。

舗装をキャンパスの基面にし、運動場の矩形だけを土にする。校舎と中庭の隙間・校舎脇・駐輪場への経路にも裸の土を残さない。運動場側と駐輪場側の帯状の植栽は z=-4〜4 の部分を空ける。運動場側は防球ネットの開口と揃うため、8m幅の通路を途中で花壇が塞がない。校舎正面の植栽も入口前は空ける。

本館と横の校舎棟は同じ屋上高さ11.6mに揃え、同じ3階分の窓の素材・屋上の柵を使う。時計塔と体育館の丸屋根だけがその上に出る。本館と横の棟はL字の角でつながる。

窓は校門の主景に合わせ、カーテン・机・廊下・階段など室内が見える落ち着いた絵にする。固定の青空・雲の反射を描かず、昼と夕方のどちらでも使えるようにする。ガラスは反射シェーダーや透明な開口ではなく、室内の絵を貼った面。

外周はネットの直後に住宅の壁を並べず、植栽と並木、舗装通路、奥の樹木帯の順に重ねる。住宅は樹木帯の奥に隠れる程度の屋根の先だけが遠景素材に含まれる。

## 構成と制約

校舎は箱の厚みを持ち、時計付き正面は切り抜きの立面図。体育館の丸屋根、ゴール、植栽の囲い、駐輪場、フェンスの柱・横桟は実際の形。細かなフェンスの網だけ繰り返しの透過テクスチャを使う。木は交差する3枚の絵で、建物と別の位置にあるため視差が出る。

地図で隠れている西側と運動場の寸法は推定。グラウンドから見える位置関係を優先した撮影セットであり、校門の既存セットと座標を共有する連続した学校モデルではない。遠景は切り抜きの板、近距離・真上から木を見ると板と分かるため、会話〜全景の撮影用。絵の光は左手前からの日中に固定。朝・昼・夕方は空と人物の光が変化するが、建物・木の絵を夜景に描き替えるものではない。

`npm run shot -- demo/painted_ground --no-dialogue --no-hud` で全方向を撮影できる。`disposePaintedGround` は共有した形・材質・テクスチャを各1回ずつ解放する。

## 中庭から使う

既存の場所 ID `courtyard` は同じセットを位置 (-27, 0, -8) に置く。`COURTYARD_ORIGIN` (27, 8) が中庭の中央通路での立ち位置の原点になり、いつもの `left` / `center` / `right` と会話カメラをそのまま使える。中央の木が会話中の人物の頭と重ならないよう、通路の軸から4mだけ西へ寄せる。場所名は「中庭」のまま。旧シナリオもこの共有3D背景を使う。

`COURTYARD_SHOTS` と中庭デモのカメラは、この中庭の原点からの相対座標。中庭のカットを運動場の場所で使うときはカメラの position / target と人物の座標に (27, 0, 8) を足す。`npm run shot -- demo/painted_courtyard --no-dialogue --no-hud` で中庭側を確認できる。

両方の場所の `stage.camera.far` は200m。既定の100mでは、離れた俯瞰カメラから校舎・外周の樹木帯が途中で切れるため。ほかの場所へ移ると未指定の100mに戻る。
