# 簡易3Dの海の見える公園（投影した地面の絵 + 動く海）

海沿いの公園の遊歩道にアバターが立ち、手すりの向こうに海と遠くの島が見える撮影用セット。作り方は painted-gate と同じマットペイントのカメラ投影だが、海は絵にせずシェーダーで描き、波とキラキラが動く。空は透過にし、ビューアの空（SkyBackground）を後ろに描く。

- 場所: `painted_seaside`（`assets/studio/locations.json` の組み込み3D背景 `builtin:painted-seaside`）
- 素材: `assets/textures/painted-seaside/`
  - `scene.avif`: 遊歩道の地面と縁石の絵（基準カメラから投影）。海・空の部分はマスクで透明
  - `tile-paving.avif`・`tile-stone.avif`: 絵が届かない面に敷く継ぎ目なしの素材（舗装は絵の板石に合わせて描いたもの、石は校門と同じ）
  - `tree-a.avif`・`tree-b.avif`・`lamp.avif`: 木と街灯の立て看板（不透明部分に切り詰めてある）
  - `far-islands.avif`: 水平線の島並み。`far-park.avif`: 陸側の公園の木々と街並み（どちらも横に繰り返す）
- サムネイル: `assets/textures/painted-classroom/thumb-seaside.avif`

## 構成

- 寸法・基準カメラ・撮影例は `layout.ts` に集約。アバターは原点、遊歩道の海側の縁は z=-2.2、海面は y=-1.6。
- 地面と縁石は `painted-gate/PaintedGate.ts` の `projectedMaterial` で投影する（絵の範囲外・裏向きの面は素材に切り替え）。
- 手すりは絵に描かず実際の形（支柱と2本の横棒）で置く。隙間から海が見え、どの向きからでも破綻しない。色は太陽の向きに合わせて2段の陰影を頂点色で付けた、光の影響を受けない素材（逆光なので手前を向いた面は陰）。
- 木と街灯は立て看板で、描画のたびにカメラの方を向く（横から見ても薄くならない）。根元にぼかした影を、太陽と反対側（手前）にずらして置く。
- 外周: 海側は水平線の島並み、陸側（南・東・西）は公園の遠景の一枚絵。ビューアの描画距離（100m）に収めること。空のドームは Studio の俯瞰表示用（ステージでは隠す）。

## 海（`Sea.ts`）

- 海面の円盤と、その周りを囲む円筒に描く。画素ごとに視線と海面（y=-1.6 の平面）の交点を求めて色を決めるので、形は「どこに海を描くか」だけを決め、海は水平線まで続く。水平線より上を向いた視線は捨てて空を見せる。
- 波: 進む正弦波と流れるノイズの高さ場。波の裏側を1段暗くし、横に引き伸ばしたノイズの稜線で細い白い波紋を描く。遠くは細部を消して落ち着かせ、水平線は霞の色になじませる。
- 照り返し: 太陽（`SUN_DIRECTION`、海の上の左奥）を映すのに必要な面の傾きが、波の向きからどれだけ外れるかで照り返しの濃さを決める（波の傾きの分布）。太陽の下に縦の光の帯ができ、濃い所は銀色にぼんやり光る。
- キラキラ: 漣に沿った細い波線を、別向きに流れるノイズで途切れ途切れの短い線にして、照り返しの帯の中だけ光らせる（中心ほど多く長い）。漣は遠いほど大きく、奥行き方向は見込み角の分だけさらに長くして画面上の大きさをそろえ、隣の大きさと混ぜて継ぎ目を出さない。白より明るくしてブルームで光らせる。
- 時間は描画のたびに時計から取る（`onBeforeRender`）ので、ステージ側に毎フレームの処理を足す必要はない。

## 絵の作り方

1. `node scripts/painted-seaside-blockout.ts <出力先>` で下書き（`blockout.png`）と地面のマスク（`ground-mask.png`）を出す。
2. codex CLI の画像生成で、`blockout.png` の上に「輪郭の位置を動かさずに」遊歩道・縁石・海・空の全体の絵を描かせる（柵・木・街灯は描かせない）。
3. 絵に `ground-mask.png` をアルファとして入れて `scene.avif` にする（`avifenc --qalpha 100`）。海と空は切り抜かれるので、絵の海は使わない。
4. 木・街灯・遠景は透過の単体の絵として描かせ、不透明部分に切り詰める。

`layout.ts` の地面・縁石・基準カメラを変えたら、下書きから描き直すこと。手すり・木・街灯・遠景・海は絵と関係なく動かせる。

## 制約

- 絵・海の色・キラキラは昼の晴れた日で固定。時間帯を夕方や夜にしても海の色は変わらない。
- 島並みは 82m 先の1枚の板なので、高い所から見下ろすと板だと分かる。会話の見せ場は `SEASIDE_SHOTS` 程度の目線の高さで撮ること。
- 逆光の場所。太陽は海の上の左奥（絵の照り返しの位置）で、キャラを照らす光と地面に落ちる影は場所の設定（`locations.json` の `light`）でこれに合わせ、影は手前右に伸びる。木と街灯の絵は左から光が当たった描き方のままなので、厳密には合っていない。
