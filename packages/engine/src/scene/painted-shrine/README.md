# 神社（簡易3D）

`builtin:painted-shrine` / 場所 `shrine_3d` / デモ `demo/painted_shrine`。
元の `shrine_far.avif`（晴天の神社）を参照し、商店街と同じく面ごとに絵を貼った建物と固定の交差板植栽で組んだ。北が -z、拝殿は南（+z）を向き、原点が会話の立ち位置。

- 拝殿（幅9m・奥行9m・壁高6m）：正面・側面は生成した正投影立面。入母屋の銅板屋根は実形状で、妻を参道へ向け、妻面は透過の絵（懸魚・飾り金具）。高欄付きの縁、木の階段、賽銭箱、鈴と鈴緒、注連縄と紙垂は立体。後ろに幣殿と本殿（切妻・千木・鰹木）。
- 社務所3棟（西に16m・10m、東に12m・南東に9m）：6m幅の立面を横に繰り返す。瓦の切妻屋根。
- 石の鳥居（z=7）、灯籠3対、拝殿前と周囲の玉垣、手水舎（瓦屋根・石の水盤・竹の樋と柄杓）、絵馬掛け、末社（小さな鳥居と灯籠付き）。
- 地面は砂利のタイルと花崗岩の参道。木は60度ずつ交差した3枚の固定板で、境内の外も鎮守の森として3重に植え、四方の外周に樹木帯。木・低木・灯籠・鳥居・手水舎・絵馬掛け・玉垣は地面に影を落とす（場所の光の向き）。
- 石・木の箱と円柱は `worldUvs` で UV を実寸に合わせ、柱や手すりで模様が伸びないようにしている。
- 空は共通の `SkyBackground`。描き込まれた光を保つため `MeshBasicMaterial`。昼専用で、夜・雨の差分はない（雨の神社 `shrine_rain` は朱の鳥居で別の構成）。

生成指示は [PROMPTS.md](./PROMPTS.md)。素材は `assets/textures/painted-shrine/`。

## 方向確認

デモは立ち位置 `[0, 1.65, 3]` を変えずに正面（拝殿）、左90度（社務所・絵馬掛け）、右90度（手水舎）、後方180度（鳥居）を撮る。ほかに拝殿の階段、手水舎の斜め、拝殿の横から本殿、拝殿前から鳥居への振り返り、俯瞰、人物との会話。

```sh
npm run validate
npm run typecheck
npm run shot -- demo/painted_shrine --no-dialogue --no-hud
```

制約：建物の中には入れない（拝殿の内部は立面の絵）。木は交差板なので真上や至近距離では板に見える。境内（x ±18、z -36〜26）の外は森で覆っているだけで、歩き回る想定はない。元の2D場所 `shrine`・`shrine_rain` は変更していない。
