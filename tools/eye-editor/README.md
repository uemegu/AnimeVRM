# Eye Atelier

ブラウザでVRoidモデルの下まぶた、目頭のアイライン、上まぶたの山の位置を編集するローカルツールです。
現在Blenderで開いている `Face` メッシュを自動解析します。
このプロジェクトのVRMビューアとは独立して動作し、追加のPythonパッケージは不要です。

## 起動と操作

1. Blenderでモデルを開き、MCPアドオンのサーバーを起動します（既定ポート9876）。
2. `Start Eye Atelier.command` をダブルクリックします。ターミナルからなら `python3 tools/eye-editor/server.py` を実行します。
3. ブラウザで <http://127.0.0.1:8765> を開き、「開いているモデルに接続」を押します。
4. 下まぶた・目頭ライン・太さ・上まぶたの山を調整します。スライダーを離すと反映されます。
5. 「変更前を見る」、左右の斜め表示、「まばたきを確認」「表情を確認」で仕上がりを確認します。
6. 「VRMを書き出す」で `output/eye-edit-日時.vrm` に保存します。編集を再開するためのファイルは「編集用の .blend を別名保存」で保存します。

保存時には目を開いた調整後の状態にします。既存ファイルは上書きしません。
保存した `.blend` をBlenderで開き、この画面から接続すると編集を再開できます。
通常のブラウザ再読み込み・編集サーバー再起動でも、Blender内の編集状態は保持します。
別モデルへ切り替える際はBlenderを再起動してください。
編集サーバーはターミナルのControl-Cで停止します。停止しても編集中の顔は残るので、必要なら先に保存してください。

## 今回の更新を使うには

起動中の編集サーバーをControl-Cで止め、同じ起動コマンドで起動し直してください。
ブラウザも再読み込みして接続します。接続時にBlender側の処理を再読み込みし、既存の調整値を引き継ぎます。
Blenderとモデルは開いたままで構いません。旧版の書き出し済みVRMは自動では更新されないため、修正版で再度書き出してください。

## 新しい調整

- **目頭の太さ（上まぶた比）**: 0%なら目頭をほぼゼロの太さにし、100%なら上まぶたと同じ基本の太さにします。つなぎ目と末端には常に短い先細りを付けます。10〜25%から試してください。
- **上まぶたの山の位置**: 0は元の形です。マイナスで目頭側、プラスで目尻側に移動します。左右の目の内外を基準に連動し、両端は固定します。目頭ラインを伸ばす場合はまず目尻側30〜60%が目安です。
- **表情を確認**: モデルの実際の表情バインドから選択肢を作ります。happy、angry、sad、母音などを確認できます。まばたきスライダーとの併用は表情の合成になるため、単独でも確認してください。

## Expression不具合の修正

旧版ではVRMのExpressionが元の非表示Faceを指したままでした。シェイプキーのコピーだけではこの参照は更新されず、VRM書き出しで表情名だけが残っていました。
修正版では接続・保存・VRM書き出し時に編集後の顔へ参照を修正し、左右の追加ラインにも同じシェイプキー名・ウェイトを登録します。元からある他のメッシュ・材質の表情バインドは保持します。
Blender内のドライバーとは別にVRMの表情バインドを持たせるため、外部ビューアでもラインが表情に追従します。
繰り返し接続してもバインドは重複しません。元の顔の頂点・シェイプキー座標は変更しませんが、ArmatureのVRM表情参照は編集後の顔に更新されます。

ブラウザのVRM書き出しは元の顔を除外し、表情プレビューを通常状態に戻して出力します。出力後はプレビュー状態を復元します。
実際の出力ファイルを読み、表情のノード・ターゲット名・ウェイト・頂点変位データを検証します。今回のモデルでは14表情×3メッシュ＝42バインドを確認しました。
Blenderの通常のExportでも修正した参照を使えますが、「Export Invisible Objects」はオフにし、変更前比較・表情プレビューを解除してから書き出してください。ブラウザの書き出しボタンがこれらを自動で行います。

## 編集方式と対象

- 今回確認したモデル: Face、4,465頂点、58シェイプキー、左右24頂点の目の縁。
- 元の `Face` とそのシェイプキーは保持し、非表示にします。
- `EyeEditor.Preview` は顔メッシュの独立コピーです。顔、既存アイラインを変形します。瞳・ハイライト・白目の形は変更しません。
- 目の縁は顔マテリアルの境界と瞳の位置から検出します。特定の頂点番号には依存しません。
- 下まぶたを部分的に持ち上げ、頬へ滑らかにつなげます。上まぶたは元の輪郭を再配置することで山を移動します。
- 追加アイラインは目の縁を補間した細いメッシュです。元の顔のボーンウェイトと表情形状に追従します。
- 表情ごとに同じ空間変形を適用します。すべての表情の品質を保証するものではありません。
- 「調整をリセット」で変形量と追加ラインをゼロにできます。元のFace自体を表示するには「変更前を見る」を使います。

## 現在の制限

VRoid由来の標準マテリアル名を持ち、ローカル座標がZ上・-Y前のモデルを対象とする試作版です。
別モデル、変更済みトポロジー、極端なサイズ、複数モデル同時編集は未検証です。
プレビューはBlenderの3Dビューの画像なので、Blenderを起動したまま使います。Blender内で別画面に切り替えた場合はLayoutに戻してください。
まばたきスライダーは `Fcl_EYE_Close` を使います。元の顔との比較は、接続時の元の表情を表示します。
ブラウザからのVRM書き出しはVRM 1.0対応です。全表情・ポーズ・外部アプリの組み合わせでの見た目を保証するものではありません。山の移動量が大きい場合は斜めからの表示とまばたきを確認してください。
保存した `.blend` には非表示の元の顔も含まれるため、そのまま全オブジェクトをVRM書き出ししないでください。

サーバーは127.0.0.1だけで待ち受け、同一オリジンとセッショントークンを確認します。
公開用サーバーではありません。ブラウザから任意のPythonコードを実行するAPIは提供しません。

## 検証

`verify_blender.py` をBlenderのPython環境で実行すると、元の顔の保持、変形、リセット、瞳の形の保持、表情データの有限性、山の移動方向、先細り、happyプレビュー、バインドの重複防止を検証します。
`verify_vrm.py` は出力GLBの表情バインドと実際のモーフ座標データを読み取ります。書き出し処理はこれに期待するバインド一覧も渡して、欠落時は成功と表示しません。
JavaScript構文は `node --check tools/eye-editor/app.js`、Python構文は `python3 -m py_compile tools/eye-editor/server.py tools/eye-editor/blender_engine.py` で確認できます。
