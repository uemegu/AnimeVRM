# Motion Mixer

起動はリポジトリ直下で `npm run dev`。表示されたURLの末尾に `motion.html` を付けて開きます（通常 `http://localhost:5173/AnimeVRM/motion.html`）。通常ビルドには既存ビューアと編集画面の両方が含まれます。

1. 左の動作をクリック、または「歩きながら挨拶」などのプリセットを選択します。プリセットは現在の構成を置き換えます。
2. 適用部位と強さを調整します。カード名を押すと開始秒・再生時間・速度・使用フレーム・フェード・ループを編集できます。タイムラインのクリックで開始秒を指定できます。
3. 再生またはシークで確認して「FBXを書き出す」を押します。

構成はブラウザに自動保存され、JSONレシピの保存・読み込みにも対応します。元のフレーム指定は30fps換算、出力は24/30/60fpsです。時間は0.5〜60秒、カードは最大32個です。下のカードが優先され、同じ部位はクォータニオン補間でブレンドします。基本ポーズは現在の姿勢に回転を加えます。基盤には自然な待機モーションを使用します。

出力はアニメーション専用の **FBX 7.4 binary**。リポジトリの `Standing Idle.fbx` の骨構造・レスト姿勢・Mixamoボーン名を保持し、合成後のローカル回転と位置を全フレームにベイクします。クリップ名は `mixamo.com`、Y-up、センチメートルです。モデルのメッシュ・テクスチャは含みません。既存の `loadMixamoAnimation` で読み込む用途です。出力ボタンでダウンロード前にFBXLoaderで再読み込みを検証します。

歩行・走行はその場動作です。水平のルート移動・足接地IKは未実装です。「髪をかきあげる」は頭の近くへ手を寄せる簡易IKを使った近似動作です。実際の髪や頭のメッシュとの衝突判定はなく、モデルの体格によって接触位置は合いません。任意のFBXの取り込みは対象外で、現在は同梱の動作ライブラリから合成します。

検証: `npx tsc --noEmit`。ローカルサーバーを5174番で起動後 `npx playwright test tests/motion-mixer.spec.js --workers=1` で操作・保存復元・FBX再読み込みの姿勢一致・スマホ幅を検証します。

## トリミング

カードを開くと「動作のトリミング」があります。「素材を見る」または素材のフレームスライダーで、その動作だけを確認できます。「このフレームから」「このフレームまで」で範囲を設定し、「範囲を適用」で合成に戻ります。元の開始・終了フレームを数値で指定することもできます。範囲の適用は再生時間を `(終了 - 開始) / 30 / 速度` 秒へ変更し、フェードを0にします。例えば先頭1秒をカットする場合は開始を30fにします。必要に応じて後からフェードを再設定できます。

## 全体ループ

再生バーの下の「全体をループ」をONにすると、本編の後ろに0〜10秒の戻り動作を追加します。6秒の本編＋1秒のつなぎなら、プレビューとFBXの両方が7秒になります。つなぎ区間は最終姿勢から先頭姿勢へ滑らかに補間し、つなぎ時間が正の場合は両端の姿勢が一致します。0秒は接続区間を追加しない設定で、もともと両端がつながる構成向けです。この場合は下地の待機動作を固定します。全体ループ中は本編の端まで届くカードの端のフェードを省き、不要な待機姿勢への戻りを避けます。カード単体のループ設定は別に維持されます。全体ループOFFでは最後で再生が停止します。

## 基本動作と肘

従来の4つの基本動作に42種類を追加しました。首の上下左右・傾き、上体の反らし・傾き・捻り、左右それぞれの腕の前方・上方・側方への伸ばし、口元・頬・胸・腰へのリーチ、指差し・ピース・親指・握りこぶし・開き手などです。分類・検索から選べます。「右手」「左手」マスクでは腕を動かさず手指だけを重ねられます。

髪をかきあげる動作と新しいリーチ動作は、肩・肘・手首の2本の骨の長さから肘位置を求めます。体に対して肘の曲がる方向を固定するため、反復IKによる肘の反転を避けられます。到達距離も骨の長さに制限します。髪・衣服との衝突判定や足接地は引き続き対象外です。

## 自分の動作ライブラリ

「今の合成を動作として保存」で名前を付けると、「自分の動作」に追加されます。合成結果を30fpsで固定した独立した動作として保存するため、保存済みの動作を材料に再び合成・保存できます。現在使っている部位のトラックを保持し、再利用時にも部位マスク・トリミング・速度・重みを変更できます。名前変更と削除に対応します。タイムラインで使用中の動作は、先にカードを削除してからライブラリから削除してください。

保存先は同じオリジンのlocalStorage（`motion-mixer-library-v1`）です。ブラウザの容量制限内で最大80件。容量不足時は保存画面にエラーを表示し、それまでの保存内容は残します。レシピJSONには使用中の保存動作も含めるので、別ブラウザへ持ち出せます。ブラウザのデータ消去に備える場合はレシピファイルも保存してください。従来のレシピはそのまま読み込めます。

追加検証: `npx playwright test tests/motion-mixer-v2.spec.js --workers=1 --output=/tmp/motion-mixer-v2-tests`。トリミング直後の姿勢、ループFBX両端、ライブラリの入れ子利用・保存復元・ファイル移行、肘の方向とシーク再現性、腕と指の独立した合成を確認します。

## カードを全体の一部分だけで使う

各カードに常時表示される「タイムラインで使う区間」の開始・終了で指定します。歩くを開始0秒・終了6秒、手を振るを開始2秒・終了4秒にすると、歩行中の2〜4秒だけ手振りが加わります。「歩きながら挨拶」プリセットもこの配置になっています。

バーの右端をドラッグすると後ろを切り詰められます。左端で開始を変更、中央で区間全体を移動できます。「再生位置で後ろをカット」は、そのカードの終了を現在位置まで短縮します。他のカードや本編全体の長さには影響しません。「次に複製」は直後に同じカードを配置します。素材の開始・終了フレームは、その区間で再生する元の動きの範囲なので、タイムラインの開始・終了秒とは別です。

## 左右の動きを交互に反復する

「この区間を繰り返す」で配置の周期を指定できます。右へ倒すカードを0〜2秒、左へ倒すカードを2〜4秒にして、両方を4秒周期にすると、右→左→右→左と本編の間で繰り返します。反復する区間はバーにも表示されます。

「左右に2秒ずつ」プリセットは8秒の本編にこの配置を作成します。基本動作は「最後の姿勢を使う」、強さは「山なりに変化」として、境目でニュートラルを通りつつ滑らかに左右へ揺れます。全体ループはON・つなぎ0秒です。「素材を繰り返す」はカード内の元モーションの再生、「この区間を繰り返す」はタイムライン上の配置の反復です。反復と強さの変化はFBXと保存動作にもベイクされます。

## 手のめり込みを調整する

髪・頬・胸・腰への接触動作は手首の目標を外側へ調整し、手を開いて手のひらを体に沿わせる向きにしています。手首だけを移動して指先が体の中へ向く状態を避けます。左右とも対応します。カードを開いた「体から離す距離」で、プラスなら外側、マイナスなら内側へ微調整できます（Mixamoスケールでのcm、VRMでは体格に応じた目安）。設定はレシピに保存され、FBXにも反映されます。

これは接触目標と手の向きの補正です。髪・服の形状を毎フレーム判定する完全な衝突回避ではないので、体格・衣服・重ねた動作によって距離の調整が必要です。

追加検証: `npx playwright test tests/motion-mixer-v3.spec.js --workers=1 --output=/tmp/motion-mixer-v3-tests`。区間外のブレンド無効化・右端ドラッグ・現在位置でのカット、反復の境目・FBX出力、接触距離の調整と保存を確認します。
