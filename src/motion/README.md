# Motion Mixer

起動はリポジトリ直下で `npm run dev`。表示されたURLの末尾に `motion.html` を付けて開きます（通常 `http://localhost:5173/AnimeVRM/motion.html`）。通常ビルドには既存ビューアと編集画面の両方が含まれます。

1. 左の動作をクリック、または「歩きながら挨拶」などのプリセットを選択します。プリセットは現在の構成を置き換えます。
2. 適用部位と強さを調整します。カード名を押すと開始秒・再生時間・速度・使用フレーム・フェード・ループを編集できます。タイムラインのクリックで開始秒を指定できます。
3. 再生またはシークで確認して「FBXを書き出す」を押します。

構成はブラウザに自動保存され、JSONレシピの保存・読み込みにも対応します。元のフレーム指定は30fps換算、出力は24/30/60fpsです。時間は0.5〜60秒、カードは最大32個です。下のカードが優先され、同じ部位はクォータニオン補間でブレンドします。基本ポーズは現在の姿勢に回転を加えます。基盤には自然な待機モーションを使用します。

出力はアニメーション専用の **FBX 7.4 binary**。リポジトリの `Standing Idle.fbx` の骨構造・レスト姿勢・Mixamoボーン名を保持し、合成後のローカル回転と位置を全フレームにベイクします。クリップ名は `mixamo.com`、Y-up、センチメートルです。モデルのメッシュ・テクスチャは含みません。既存の `loadMixamoAnimation` で読み込む用途です。出力ボタンでダウンロード前にFBXLoaderで再読み込みを検証します。

歩行・走行はその場動作です。水平のルート移動・足接地IKは未実装です。「髪をかきあげる」は頭の近くへ手を寄せる簡易IKを使った近似動作です。実際の髪や頭のメッシュとの衝突判定はなく、モデルの体格によって接触位置は合いません。任意のFBXの取り込みは対象外で、現在は同梱の動作ライブラリから合成します。

検証: `npx tsc --noEmit`。ローカルサーバーを5174番で起動後 `npx playwright test tests/motion-mixer.spec.js --workers=1` で操作・保存復元・FBX再読み込みの姿勢一致・スマホ幅を検証します。
