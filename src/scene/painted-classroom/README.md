# 元画像の構図を保つ教室GLB

成果物: `public/models/school-environments/school-classroom-far2-standee.glb`

元画像 `school-classroom-far2.avif` の配置・遠近・重なりを保存する撮影用セット。単体の机を並べる方式ではなく、元画像の机の横一列を1メッシュにまとめ、6層の画像カードとして奥行きに配置する。中央通路を空けるため、各列メッシュの左右は同一平面上の2領域。机の脚・天板等を立体化していない。

背景は元画像を床・壁・天井の簡単な形状に投影し、同じ画像を列カードにも使う。描き足した窓・黒板・家具で元絵を再構成する方式ではない。小さな視点移動で境界から穴が見えないよう、最奥に補助の画像面を置く。

## 基準カメラとアバター

GLBには `Reference camera | original image composition` を内蔵。基準は位置 `[0, 1.25, 0]`、注視点 `[0, 1.19, -1]`、垂直FOV50度、アスペクト比1672:941。基準カメラから元画像と同じ構図になるよう各面のUVを設定している。補間と画像フィルタによる微小差はある。

アバターの推奨位置は `[0, 0, -1.9]`。教室の奥ではなく、手前の会話距離に置く。アバター自体はGLBに含まない。

- GLB確認: `/AnimeVRM/painted-classroom.html`
- シナリオ: `/AnimeVRM/scenarios/painted-classroom.html`
- シナリオ指定: `stage: 'painted-classroom'`
- 確認ページの「元絵の構図」→「アバターを隠す」→「元の1枚絵と比較」で背景を比較できる。
- 確認ページもシナリオも書き出したGLBを `GLTFLoader` で読む。

## 撮影範囲と制約

基準カメラ（引き）では左右約12cmまで。会話距離（アバターまで約1.3m、FOV 30度前後）に寄れば、左右約±40cm・前方約0.9mまで破綻しない。これより広角・大きな横移動では投影シェルの端（右壁の切れ目など）が見える。シェルは元画像の外まで伸びているので、読み込み時にテクスチャをミラー折り返しにして、端のピクセルが横スジ状に伸びるのを防いでいる。

会話シナリオ（`paintedClassroomScenario.ts`）はこの範囲で、元絵の構図の引き・2ショット・通路からの切り返し・バストアップを組んでいる。列カードには元画像の影や机間の隙間も残すため、大きな横移動や俯瞰では切れ目や重なりが見える。元画像で隠れた部分を完全に復元したものではない。自由移動・背面からの撮影用の教室ではない。

テクスチャとカメラはGLB内蔵。外部画像や独自シェーダーは不要。`KHR_materials_unlit` と通常のUVを使用する。画像をそのまま使う今回の版では追加の画像生成は行っていない。以前生成した単体机素材と生成プロンプトは残しているが、このGLBには使用していない。

組み立ては `createPaintedClassroom()`、書き出しはブラウザ上の `exportPaintedClassroom()`。戻り値のArrayBufferをGLBとして保存する。現在のファイルはこの関数から書き出したもの。

検証: 基準カメラのGLB描画と同じAVIFの平面表示を1672×941でピクセル比較。6つの列メッシュ、全カメラ、比較切替、アバター表示切替、型チェックを確認する。テストは既存方針によりGit除外の `tests/`、画像は `output/` に保存。
